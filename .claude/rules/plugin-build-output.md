# Rule: plugin/ is partly build output

- `plugin/**/*.mjs` and `plugin/.claude-plugin/plugin.json` are generated by `pnpm build` from `../src/*.mts` and `../plugin.json`. Never edit them. Edit the source and rebuild.
- Everything else in `plugin/` (`skills/*/SKILL.md`, `hooks/hooks.json`, `agents/*.md`, `README.md`) is hand-written and edited in place.
- Hook/script paths inside `hooks.json` use `${CLAUDE_PLUGIN_ROOT}/…` and point at the generated `.mjs` file, not the `.mts` source.
- Runtime code must only import `node:` builtins — no `node_modules` at install time.
