# universal-lint evaluation 2026-11-26b (plugin 0.18.0)

Release check of 0.18.0 (mod plus one stdio MCP server per session, `mcp_tool` hooks, command hook only for the watch list; design in [hook-design.md](../design/hook-design.md) "Surface", delivery in [settle-window.md](../design/settle-window.md)) on branch `feature/universal-lint-mod-server`, built plugin of the committed code. The engine facts the design rests on (F-P1 to F-P8) and the probe rounds are in [EVALUATION-2026-11-26-mod-server.md](EVALUATION-2026-11-26-mod-server.md) and are not repeated here.

**One machine**: WSL2 (kernel 6.18.58.1-microsoft-standard-WSL2), Node 24.22.3 on PATH (builds through pnpm with the preset's Node 26 requirement), Claude Code 2.1.332, managed settings present (the same machine and policy as the probe rounds). Real linter for every finding: ruff 0.17.6 on PATH (installed with `uv tool install ruff`), no project config, so its default rule set; the findings seen were F401 (unused import), I001 (unsorted import block) and F821 (undefined name). No stub linter was used.

## Method

- **Local gate**: `pnpm install --offline`, `pnpm lint` (oxlint plus `wiki-check.ts`), `pnpm -r build`, `node development/scripts/check-plugin-layout.ts`, `pnpm --filter universal-lint test`, `pnpm --filter universal-lint test:plugin`, the `shared-code`, `dprint`, `universal-format` and `graphmind-helper` suites, `claude plugin validate universal-lint/plugin`.
- **Headless runs**: `claude -p --plugin-dir universal-lint/plugin --setting-sources project --output-format json --debug-file <log>` in a fresh throwaway git repository per case (one committed `w.py`, `print("hello")`, which the SessionStart watch list picks up; `.claude/` git-ignored), `--allowedTools Write,Edit,Read,Bash,Agent,EnterWorktree,ExitWorktree` (L12 also the two model-visible server tools). Carriers were read from the session transcript and the subagent transcripts: `hook_blocking_error` and `stop_hook_summary` for a Stop/SubagentStop block, `hook_additional_context` with `hookName` `tool.call` for in-turn context and `UserPromptSubmit` for the wake.
- **Interactive runs**: `claude` in a detached tmux session (200x50) with the same flags minus `-p`, trust dialog Down then Enter, prompt typed literally, 2 s, then Enter as its own key. The driver polled the transcript for `stop_hook_summary` records and for the user record of the wake prompt, then waited 40-45 s more (beyond the 20 s quiet time plus the lint) before counting both.
- **L8 wall time**: the same no-edit prompt ("Reply with the single word ok."), twice with and twice without `--plugin-dir`, alternated; `next_report` lines of the debug log counted.

## Bug hunt

No `bughunt` skill run in this evaluation; the branch's combined review follows in the delivery pipeline. Found by the live runs: no defect.
